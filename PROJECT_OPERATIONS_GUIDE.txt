RUN PROJECT
-----------

TERMINAL 1

cd ~/ALLdev/ArkDev/apps/api
npm install
npm run dev


TERMINAL 2

cd ~/ALLdev/ArkDev/apps/web
npm install
npm run dev


BUILD PROJECT
-------------

cd ~/ALLdev/ArkDev/apps/api
npm run build

cd ~/ALLdev/ArkDev/apps/web
npm run build

WHEN ADDING NEW FEATURE
-----------------------

1. Create backup

cp file.ts file.ts.backup

2. Edit code

3. Verify

npm run build

4. Test route

5. Commit

git add .
git commit -m "feature"

6. Push

git push origin main

7. Remove backup

rm *.backup
